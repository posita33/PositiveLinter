# PositiveLinter

PositiveLinter is an Unreal Engine 5.7.4 editor plugin for validating assets and
naming conventions. It is the maintained successor to this project's UE 4.27
Linter release.

## Installation

Copy `Plugins/PositiveLinter` into your project's `Plugins` directory, regenerate
project files if necessary, and enable **PositiveLinter** from the editor's
Plugins window. The legacy folder and module identifiers are deliberately kept
so existing rule-set assets continue to load without redirects.
